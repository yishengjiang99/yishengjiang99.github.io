# Yisheng Jiang

Personal landing page for [yishengjiang99.github.io](https://yishengjiang99.github.io/).

A short hero, then one card per project (FinalCap, ProTune AI Camera, Music Reader, AI Music Radar, gbk) with its screenshots. GitHub Pages serves [`index.html`](./index.html) from the root of `master`. No build step.

- `img/<project>/*.webp`: App Store / app screenshots from each project's repo, 600px and 300px wide.
- `fonts/`: self-hosted, subset Fraunces and Outfit (SIL Open Font License 1.1).
- `og.jpg`: 1200×630 social preview.
